## 怎么试（拖动 / 纵轴）

1. 打开 →「使用 X 授权登录」→「授权并继续」
2. 进入气泡画布：**上方 = 高回复（高互动分）**，**下方 = 低回复**；气泡大小跟互动总量（对方回我 + 我回对方）
3. **拖动**任意气泡：限制在画布框内；松手后停在新位置（**不回弹、不强制吸附层**）
4. 点选 / 拖动气泡会打开底部详情（对方回我 / 我回他 / 标签 / 预览）
5. 顶栏两排：筛选全部·铁粉·粉丝·路人；分享 / 账号 / 退出
6. 页面本身**不滚屏**（`overflow:hidden` + 画布 `overflow:hidden`），人物缩放到一框内可见

## 纵轴含义

- y 由互动分映射：`score = 对方回我×2 + 我回对方×1 + 双向额外+1`
- 高分在上层，低分在下层；初始布局还有按分层 + x 分散 + 碰撞微推，保证一屏全显示

## 已知局限

- 仍为静态示例 + 演示授权，无真 X OAuth / API
- 拖动后位置不持久（刷新重布局）；详情条展开会略压缩画布高度并触发轻量重排
- 人数多时靠碰撞微推挤进一屏，极端密集时气泡会变小、重叠风险上升
